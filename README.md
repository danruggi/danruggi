### 👋 About me

I'm a senior developer from Italy building **data and automation systems that run unattended in production**.
Most of my work is private client work: scrapers, AI content pipelines and analytics platforms for media, marketing and travel companies. What you see here is the open-source side.

- 🕷️ **Web scraping at scale**: async crawlers, anti-bot fallbacks, proxy rotation, headless browsers
- 🎬 **AI content pipelines**: script → AI video → voiceover → edit → publish, fully automated
- 📊 **Data platforms**: ClickHouse warehouses, FastAPI/Flask APIs, React dashboards
- 🛠️ **Ops**: Linux servers, Proxmox, systemd, one-command deploys

> 💼 **Open to freelance projects.** Message me on [LinkedIn](https://www.linkedin.com/in/daniele-rugginenti/).
